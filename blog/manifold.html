A Life on Manifold

Pushkar Khetrapal July 2026 8 min read

Have you ever wondered how a rotation matrix changes over time?

Imagine a rigid object resting in space. At time (t=0), it has some initial orientation. Now suppose a force or torque is applied to it. As the object rotates, its orientation continuously changes until it eventually reaches a new pose. Rather than viewing this motion as a sequence of disconnected orientations, we can think of the orientation as a continuous function of time.

Consider two coordinate frames:

  • The world frame, which remains fixed.
  • The object frame, which is attached rigidly to the object.

For simplicity, assume that at $t = 0$:

  • The origins of the world and object frames coincide at $[0,0,0]$.
  • The object has no initial rotation.

Therefore, the transformation from the object frame to the world frame is simply the identity matrix.

$$R(0) = I$$

A force is applied to the object.

As the object rotates, the object's coordinate frame rotates along with it. Although the environment remains fixed, the coordinates of every landmark expressed in the object frame begin to change because the reference frame itself is changing. After some time (t), the object has reached a new orientation. The orientation of the object relative to the original frame can be represented by a $[R|t]$.

Transformation matrix can easily tell how much the object has rotated from the original frame.

Note : As we are using a rigid body, the object will always maintain the same shape and size in any form. This has a special group of transformations called the Special Orthogonal Group (SO(3)). Which says the basis of R(t) will always be orthonormal and the det(R(t)) will be 1.

So, Do we really need to [3x3] Matrix to describe the orientation of an object?

The answer to above is very simple. No, we don't need [3x3] Matrix to describe the orientation of an object. We can use quaternions, rotation vectors, Euler angles to describe the orientation of an object. But still we use rotation matrices to describe orientation because it just not store information about the orientation But also has a power to transform the complete space itself. Also, if you look closely, you will see that the [3x3] Matrix doesn't have 9DOF, due to the constraints of the SO(3) group. It has 3DOF only but represents by 9 numbers.

Now, coming back to the original question, how a rotation matrix changes over time?

We know,

$$R(t).R(t)^T = I$$

For every time t.

Differentiating both sides with respect to time, we get:

$$\frac{d}{dt}(R(t)\,R(t)^T) = 0$$

Using the product rule, we get:

$$\frac{d}{dt}R(t)\,R(t)^T + R(t)\,\frac{d}{dt}R(t)^T = 0$$

Rearranging, we get:

$$\frac{d}{dt}R(t)\,R(t)^T = -R(t)\,\frac{d}{dt}R(t)^T$$ (i)

Assume,

$$A = \frac{d}{dt}R(t)\,R(t)^T$$
$$B = R(t)\,\frac{d}{dt}R(t)^T$$

Taking transpose of A,

$$A^T = (\frac{d}{dt}R(t)\,R(t)^T)^T$$

Using $(XY)^T = Y^T.X^T$

$$A^T = (R(t)^T)^T.(\frac{d}{dt}R(t))^T$$
$$A^T = R(t).(\frac{d}{dt}R(t))^T$$

Which is nothing but B. So, $$A^T = B$$ Substituting in (i), we get $$A = -A^T$$

Which tell something great here, A is skew matrix.

Assume any matrix m, if $m = m^T$ then it states that Upper trangular matrix has to be equal to lower trangular matrix. Only 6 elements required to form a matrix. Now, if $m = -m^T$, look closing the diagonal of m has to be 0, since taking Transpose not moving diagonal anywhere, and we are stating that the diagonal values will be negative after Transpose, which only being statisfy when zero diagonal matrix. So, A skew matrices has only 3 DOF for 3x3 matrix. This can be represent as a vector.

$$A = \phi(t)$$
$$\frac{d}{dt}R(t)\,R(t)^T = \phi(t)$$ (ii)

Above equation (ii), $\frac{d}{dt}R$ multiply by $R^T$ on right side represents important thing. multiplying by $R^T$ is simply reverses the rotation. $\frac{d}{dt}R$ describes how the rotation matrix is changing over time. By multiplying it with R^T, will remove the current orientation and express the change relative to the identity rotation. In other words, $\frac{d}{dt}R.R^T$ tells us the local or instantaneous rotational change, independent of the object's current orientation.

in equation (ii) multiply by R(t) both sides

$$\frac{d}{dt}R(t)\,R(t)^T.R(t) = \phi(t)R(t)$$
$$R(t)^T.R(t) = I$$
$$\frac{d}{dt}R(t) = \phi(t)R(t)$$

This is nothing by another form of $\frac{d}{da}e^a = a.e^a$.

So, from above,

$$R(t) = e^\phi(t)$$ (iii)

Above derivation laid the basic ground for Lie theory. Lie theory states that Rotation matrix $SO(3)$ forms a 3D manifold in 9 dimension space. And this manifold is continous nature in space. The vector $\phi(t)$ is tangential vector to the manifold at point $R$.

Any point on the manifold represent by a rotation matrix $R(t)$. Think like a earth surface, every point on earth surface represent by a latitude and longitude. So, similarily any point on the manifold represent by a SO(3) matrix $R(t)$. Since, manifold is a curvature space, so at every point on the manifold, there is a tangent plane. Tangent plane near R will be represent how fast the curve is changing near to that point.

Manifold : Where the R(t) live. In general rotation matrix forms 9 dim  curve only, As The SO3 matrix is bound by two condition which forced the curve should be in 3 dimensions.

Tangent Space around R(t) : Represent local variation around that region. Think Like a mountain, you can go anywhere, in any direction, depending upon direction you have to walk steep or slope from same point.
