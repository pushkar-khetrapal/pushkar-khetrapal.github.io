A Life on Manifold

Pushkar Khetrapal July 2026 8 min read

Transformers replaced recurrence with a simple idea: let every token look at every other token and decide how much to pay attention. The mechanism is called self-attention, and once you see the matrix version, most of the architecture clicks into place.

The core equation

Given input embeddings packed into a matrix $X$, we learn three projection matrices $W_Q$, $W_K$, and $W_V$ to form queries, keys, and values:

$$Q = XW_Q,\quad K = XW_K,\quad V = XW_V$$

Scaled dot-product attention computes a weighted sum of values, where weights come from how similar each query is to each key:

$$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

The scaling factor $\sqrt{d_k}$ keeps dot products from growing too large as dimension increases, which would push softmax into regions with tiny gradients.

What the model is actually doing

Think of attention as a soft lookup table. The query asks a question. Keys advertise what each position offers. Softmax turns match scores into a probability distribution. Values are mixed according to those probabilities.

Attention is not magic — it is differentiable content-addressable memory with a temperature controlled by $\sqrt{d_k}$.

Multi-head attention

Instead of one attention operation, transformers run $h$ heads in parallel, each with its own projections, then concatenate and project again:

$$\text{MultiHead}(X) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)\,W_O$$

Different heads often specialize: one may track syntax, another long-range dependencies, another local patterns. You do not hard-code this — it emerges from training.

A minimal PyTorch sketch

import torch
import torch.nn.functional as F

def attention(q, k, v):
    scores = q @ k.transpose(-2, -1) / (q.size(-1) ** 0.5)
    weights = F.softmax(scores, dim=-1)
    return weights @ v

That is the heart of the transformer block. Everything else — positional encodings, layer norm, feed-forward MLPs, residuals — is scaffolding that makes this trainable at scale.
